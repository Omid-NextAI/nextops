# فناوری‌های جاری و گزینه‌های آینده

[English](../en/TECH_STACK.md) · [فهرست](INDEX.md) · [معماری](ARCHITECTURE.md) · [نمودارها](DIAGRAMS.md) · [ارزیابی CPU](CPU_AI.md)

## بخش مستقر کنترل‌شده، ۷ اکتبر ۲۰۲۶

این راهنما مخزن و استقرار تثبیت‌شدهٔ جاری را شرح می‌دهد، نه برنامهٔ جایگزینی فناوری.
[وضعیت انتشار](../status/current-release.yaml) مرجع هویت خدمت و شناسهٔ فایل‌هاست؛
[pyproject.toml](../../pyproject.toml) و [uv.lock](../../uv.lock) تعریف بسته و نسخهٔ حل‌شده را
نگه می‌دارند. کد برنامه/API/MCP برابر `52e5179` است. استفادهٔ کنترل‌شده، پذیرش تولید نیست.

|---|---|---|

SDK رسمی MCP اکنون مستقر است و وابستگیِ ارزیابی‌نشدهٔ آینده نیست. خدمت HTTP قدیمی غیرفعال
و فقط برای بازگشت دقیق حفظ است. سرور Zabbix دوم، اتصال API مصوب است؛ پشتهٔ Docker موجودِ
آن نه فناوری استقرار NextOps است و نه پایگاه تازهٔ تحت مدیریت آن.

## نمایهٔ منتخب مدل و محدودیت آن

نمایهٔ تثبیت‌شده۳۲ worker، یک slot بومی، زمینهٔ تنظیم‌شدهٔ16K، شش نوبت کاملِ ذخیره‌شده،
یک درخواست فعال/دو منتظر و استدلال خاموش دارد. مهلت صف/provider/برنامه/پراکسی، ۵/۳۰۰/۳۳۰/۳۶۰
ثانیه و سقف حافظهٔ بومی۹۶ GiB ثابت است. تخصیص مهمان و RAM ظاهراً آزاد میزبان، اندازه‌گیری
کیفیت، هم‌زمانی قابل‌استفاده یا نزدیکی NUMA نیست.

کیفیت خام۱۳ از۱۶ با استثنای ثبت‌شدهٔ مالک همچنان ناموفق است. استدلال/حریم خصوصی، کیفیت کل
زمینه و پذیرش WAN/VM/بارِ همین کد بازند. این تنظیم، ادعای جدیدترین مدل فروشنده، درستی همگانی
یا سریع‌ترین گزینهٔ CPU نیست. نامزد با فایل ثابت و معیار اندازه‌گیری‌شده مقایسه شود؛
[هوش مصنوعی CPU](CPU_AI.md) و [آزمون](TESTING.md) مرجع‌اند.

## قرارداد رابط و داده

پیاده‌سازی ماژولار و ایستای فعلی حفظ شود. `app.js`، `theme.js`، `capabilities.js` و
`investigation-view.js` از API موجود استفاده می‌کنند؛ مسئولیت CSS و فایل محلی جداست.
`pyproject.toml`، فایل‌های `static/*` را در wheel می‌گذارد. برای گراف بستهٔ فرانت‌اندی که
وجود ندارد، lockfile لازم نیست؛ افزودن React فقط برای تطبیق پیشنهاد قدیمی، بازسازی معماری
فعال است.

وضعیت رابط نه مجوز می‌دهد و نه شاهد کش‌شده را جای خواندن تازه می‌گذارد. سابقهٔ گفت‌وگو
متعلق به بک‌اند و مخصوص مالک است؛ ترجیح ظاهری پوسته جدا می‌ماند. شناسه/کد فنی در RTL
چپ‌به‌راست، زمان ذخیره UTC، فونت محلی خوانا، خطای آشکار، دسترسی صفحه‌کلید و پاک‌شدن نمای حساس
هنگام خروج حفظ شوند.

## گزینه‌های حفظ‌شدهٔ آینده، نه قابلیت نصب‌شده

انتخاب‌های پیشین طراحی حفظ می‌شوند، بدون آنکه پیاده‌سازی امروز معرفی شوند. استفاده از هرکدام
به مشخصات محدود، ADR مرتبط، آماده‌سازی آفلاین، پذیرش دوزبانه و منفعت سنجیده نیاز دارد.

| گزینه | شرط مناسب | الزام حفظ‌شونده |
|---|---|---|
| worker عمومی PostgreSQL، واگذاری کار/checkpoint/outbox | نیاز واقعی به اجرای ناهمگام ماندگار فراتر از کاربرد محدود جاری | ممیزی، بازبینی مجوز، idempotency و بررسی نتیجهٔ نامشخص |
| React/TypeScript/Vite و shadcn/ui/Tailwind/i18next/TanStack Query بازبینی‌شده | مهاجرت توجیه‌شده، نه صرفاً بازسازی تصویر مرجع | خروجی محلی، نشست، جداسازی مالک، EN/FA و دسترسی‌پذیری |
| بازیابی محلی/pgvector و encoder/reranker اختیاری CPU | منفعتِ ارتباط دوزبانه و فیلتر مجوز | منشأ سند جدا از شاهد زنده؛ بدون بردارسازی راه‌دور |
| React Flow/توپولوژی | وجود API توپولوژی مجاز و محدود | منشأ/تازگی، مسیر صفحه‌کلید و شروع فقط‌خواندنی |
| OpenTelemetry/Prometheus/Grafana محلی | نیاز عملیاتی مشخص به مشاهده‌پذیری | پالایش و دادهٔ محلی؛ ممیزی امنیتی مستقل می‌ماند |
| Redis یا چارچوب گردش‌کار دیگر | اثبات کمبود با اندازه‌گیری | مرجع PostgreSQL و سازگاری بازیابی/تأیید |
| محیط CPU دیگر یا نمونهٔ مدل بیشتر | توجیه مهاجرت/پیچیدگی با benchmark | بدون ابر/نیاز GPU؛ قالب، سقف منابع و بازگشت ثابت |
| Compose در مهمان‌ها | نیاز استقرارِ جداگانه بازبینی‌شده | فایل آفلاین بدون pull، بدون سوکت کانتینر و مرزهای هم‌ارز |

اتصال‌های گسترده و اصلاح کنترل‌شده در نقشهٔ راه می‌مانند، نه اتصال فعالِ ساختگی.
Kubernetes، Kafka، service mesh، مدل راه‌دور و آموزش مدل پایه، لازمهٔ بهبود مسیر شاهد نیستند.

## نظم بسته‌بندی و انتشار

کتابخانهٔ بومی/runtime، wheelهای Python، رابط/ترجمه/فایل مستندات API، مدل/قالب و وابستگی
مرورگر آزمون از پیش آماده شوند. نبود فایل باید preflight/readiness را رد کند، نه دریافت
پنهانی. مجوز، هش، کد دقیق و گزینهٔ ساخت در manifest موجود بمانند. ابزار توسعه خودبه‌خود
وابستگی اجرا نیست.

CI در GitHub بدون اطلاعات ورود زیرساخت اجرا می‌شود و PostgreSQL 16، نسخهٔ اصلیِ مستقر،
و17 را می‌آزماید؛ سبز بودن آن نه حفاظت شاخه را تنظیم می‌کند و نه انتشار را مستقر.
[توسعه](DEVELOPMENT.md)، [اجرای آفلاین](OFFLINE_RUNTIME.md) و
[پذیرش محدود جاری](../requirements/AUDIT_REPAIR_LIVE_QUALIFICATION_2026-10-07.md) مرجع‌اند.
بازیابی مستقل به دستور مالک در تعویق است، نه موفق.
