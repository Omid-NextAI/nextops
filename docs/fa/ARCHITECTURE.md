## سامانهٔ جاری: استقرار کنترل‌شده، ۷ اکتبر ۲۰۲۶

برنامه، API مدل و درگاه اصلی MCP/اجراکننده با کد دقیق `52e5179` تثبیت شده‌اند و گردآورندهٔ
Linux متناظر روی چهار مهمان موجود نصب است. این وضعیت، آزمون کنترل‌شدهٔ کاربران است، نه
پذیرش کامل تولید. [مانیفست انتشار](../status/current-release.yaml) مرجع شناسه و نتیجهٔ
معیارهاست؛ [رکورد تاریخ‌دار زنده](../requirements/AUDIT_REPAIR_LIVE_QUALIFICATION_2026-10-07.md)
مشاهدات پذیرش را نگه می‌دارد. تغییر این راهنما نه استقرار کد است و نه گسترش پذیرش.

هستهٔ ماژولار حفظ شود؛ جداسازی فرایند زمانی لازم است که حفاظت از اطلاعات ورود، شبکه یا منابع
آن را توجیه کند. برنامهٔ جاری، بررسی محدود را از کاربردهای API اجرا و نتیجه و ممیزی را در
PostgreSQL ذخیره می‌کند. پردازشگر عمومی ماندگار، خدمت بازیابی اسناد، خدمت توپولوژی و اجراکنندهٔ
تغییر زیرساخت مستقر نیستند. این‌ها طرح مقصد هستند، نه دلیل بازسازی مسیر فقط‌خواندنیِ فعال.

## جانمایی و مرزهای اعتماد

چهار مهمان موجودِ Ubuntu روی یک میزبان ESXi/G10، یک حوزهٔ خرابی دارند و دسترس‌پذیری بالا در
برابر از دست رفتن میزبان ایجاد نمی‌کنند. جدول منابع اولیه در راهنماهای شروع و ذخیره‌سازی،
نمایهٔ تاریخی آماده‌سازی است، نه ظرفیت آزاد امروز یا منابع فعلیِ ماشین بزرگ‌شدهٔ AI.

| نقش | مسئولیت جاری | مرز |
|---|---|---|
| ماشین برنامه | Nginx/TLS، پنل ایستای EN/FA، برنامهٔ FastAPI، هویت محلی و PostgreSQL محدود NextOps | سیاست برنامه مجوز کاربر جاری را می‌سنجد؛ اطلاعات ورود یا مسیر مستقیم به تجهیزات ندارد |
| ماشین AI | API محافظت‌شدهٔ مدل و یک خدمت ثابت و محلی llama.cpp روی CPU | فقط پرسش، سابقه و شاهد پالایش‌شده؛ بدون اطلاعات ورود مقصد، جایگزین ابری یا دسترسی به تجهیزات |
| ماشین موجودِ اتصال‌دهنده | درگاه `nextops-mcp.service` و اجراکنندهٔ `nextops-source-runner.service` | هویت خدمت جدا؛ فقط اجراکننده توکن/کلید SSH مقصد و دسترسی مجاز شبکهٔ داخلی دارد |
| ماشین اختصاصی Zabbix | خدمت/API منبع اصلی، PostgreSQL جداگانه و گردآورندهٔ Linux موجود | پایگاه NextOps نیست؛ فقط از اتصال‌های مصوب خوانده می‌شود |
| Zabbix دومِ موجود | منبع API مجازِ دیگر، بیرون از استقرار چهار نقش | اتصال فقط API؛ مدیریت سرور یا ساخت ماشین جدید از آن نتیجه نمی‌شود |

برنامه از تونل‌های SSH جدا و محدود با هویت میزبان تأییدشده به AI و MCP می‌رسد. انتقال MCP،
Streamable HTTP احرازهویت‌شده با TLS و SDK رسمی Python با نسخهٔ ثابت است. درگاه و اجراکننده
از سوکت Unix با کنترل UID همتا در هر دو جهت استفاده می‌کنند. درگاه فقط loopback دارد و
اطلاعات ورود یا مسیر شبکهٔ مقصد را ندارد. هویت خدمتِ استقرار جای مجوز کاربر جاری در برنامه
را نمی‌گیرد.

خدمت قدیمیِ HTTP اتصال‌دهنده غیرفعال است. فایل‌های اصلی آن برای بازگشت دقیق نگه‌داری می‌شوند،
نه اتصال زندهٔ موازی، جایگزینی خودکار یا مسیر دورزن مجوز. [قرارداد MCP](MCP.md)،
[تصمیم 0010](../adr/0010-source-scoped-zabbix-mcp.md) و `deploy/mcp/` را ببینید.

## مسیر جاری بررسی و ارائهٔ نتیجه

۱. ورود محلی، تعیین اتصال منبع/مقصد مصوب، کنترل دامنهٔ کاربر جاری و ثبت بررسی محدود.

۲. فراخوانی خواندن نام‌دار MCP؛ درگاه/اجراکننده هویت، هش اتصال، شناسهٔ همبستگی، عملیات، دامنه،
مهلت و سقف پاسخ را می‌سنجند. اجراکننده از گردآورندهٔ محدود Zabbix یا Linux با فرمان اجباری
استفاده می‌کند؛ نشانی دلخواه، روش آزاد JSON-RPC و فرمان shell ابزار سامانه نیستند.

۳. اعتبارسنجی شاهد برگشتی و پالایش رازهای شناخته‌شده پیش از پرامپت، هش، ذخیره یا پاسخ؛ شمارش،
محدودشدن نتایج و پوشش در کد و در همان دامنهٔ مجاز محاسبه می‌شوند.

۴. تولید محلی و سپس کنترل قطعی یکپارچگی پاسخ؛ دانش عمومی مدل، سابقهٔ گفت‌وگو و شاهد تازهٔ
زیرساخت از یکدیگر جدا می‌مانند.

۵. کنترل دوبارهٔ نشست/کاربر/دامنه/منبع جاری و ذخیرهٔ اتمی نتیجه، هش شاهد و ممیزی الزامیِ پایان
پیش از ارائهٔ موفق؛ خواندن مجاز هم ممیزی لازم دارد و شکست نباید دسترسی موفقِ ثبت‌نشده بسازد.

پالایش راز، لایهٔ دفاعی است و تضمین همهٔ قالب‌های ممکن نیست. برنامه مجوز به‌روزرسانی مقصد
ندارد؛ تغییر خارج از برنامه با دسترسی ممتاز به توقف پذیرش کنترل‌شده نیاز دارد. کنترل‌های
دیرهنگامِ پیاده‌شده، تضمین سریال‌پذیری همهٔ تغییرها نیستند.

فهرست محافظت‌شده دو منبع و هفت مقصد مصوب دارد؛ خواندن محدود سه مقصد منبع دوم پذیرفته شده است.
نمایش فهرست، فرادادهٔ مجاز است، نه کشف شبکه، افزودن همهٔ گروه‌ها یا اثبات سلامت. موفقیت API،
فعال بودن میزبان، دسترسی‌پذیری و سلامت موتور پایش، واقعیت‌های جدا هستند. نبود، کهنگی و ناقص
بودن شاهد آشکار می‌ماند.

## مدل، حافظه و رابط

برچسب تنظیم‌شده Qwen3.8-27B Q8 است؛ اجرا روی CPU با۳۲ worker، یک slot بومی، زمینهٔ تنظیم‌شدهٔ
16K، شش نوبت کاملِ ذخیره‌شده، استدلال خاموش و یک درخواست فعال/دو منتظر انجام می‌شود. مهلت
موجودِ صف/provider/برنامه/پراکسی، ۵/۳۰۰/۳۳۰/۳۶۰ ثانیه است. شناسهٔ فایل‌ها در manifest و
نمایهٔ مدل نگه‌داری می‌شود، نه موجودی مستقل در این راهنما. ظرفیت تنظیم‌شده، پذیرش کیفیت کل
زمینه یا تضمین توان عملیاتی نیست.

ظرفیت بومی هنگام لغو یا پایان مهلت تا تأیید پایان واقعیِ فراخوانی حفظ می‌شود؛ نامشخص بودن
بیکاری، درخواست تازه را رد می‌کند. سلامت API اثبات بیکار بودن مدل نیست و لغو مرورگر، توقف
تولید راه‌دور را ثابت نمی‌کند.

گفت‌وگوی مخصوص مالک از مسیرهای موجود PostgreSQL و سابقهٔ محدود استفاده می‌کند، نه آموزش مدل
یا حافظهٔ نامحدود. خروج، وضعیت حساس نما را پاک می‌کند. پنل جاری HTML/CSS/JavaScript محلی است
و EN/FA، ‏RTL/LTR، ترجیح ماندگار پوسته و شاهد بازشونده دارد. ورود از تصاویر اصلیِ روشن/تیرهٔ
OCS و ترکیب ثابتِ نشان شرکت استفاده می‌کند؛ دروازهٔ متحرکِ پیشین، ورود منتخب نیست.

## ساختار واقعی کد و استقرار

```text
packages/nextops/
  api/                 # FastAPI composition and static/* presentation assets
  application/         # identity, investigations, source access, conversations, users
  contracts/           # typed request/result/evidence contracts
  domain/              # entities and invariants
  policy/              # deterministic authorization and answer integrity
  inference/           # local providers, capabilities and bounded admission
  connectors/          # real MCP gateway/runner, scoped Zabbix/Linux drivers
  persistence/         # PostgreSQL repositories and transactions
  security/            # trust, authentication, catalogs and secret handling
migrations/            # Alembic migrations
deploy/                # native systemd, MCP, inference, TLS and installer profiles
scripts/               # validators, isolated qualification and lifecycle tooling
tests/                 # unit/API, real PostgreSQL, protocol and browser coverage
docs/                  # maintained EN/FA guides, requirements, ADRs and evidence
pyproject.toml         # Python/package definitions and static asset inclusion
uv.lock                # reviewed resolved dependency lock
```

`apps/worker`، `knowledge` یا `observability` صرفاً برای تطبیق نمودار آینده ساخته نشوند.

## معماری آینده و پذیرش باقیمانده

پردازشگر عمومی ماندگار، بازیابی/بردارسازی اسناد، توپولوژی، اتصال‌های بیشتر و اصلاح مجاز،
قابلیت‌های محدود آینده‌اند. React/Vite و کتابخانه‌های اختیاری، پیشنهادند نه رابط مستقر.
مهاجرت به شاهد منفعت، بسته‌بندی آفلاین سازگار، ADR مناسب و آزمون نیاز دارد؛ خود MCP سامانهٔ
مجوز نیست.

نتیجهٔ خام مدل۱۳ از۱۶، با استثنای ثبت‌شدهٔ مالک همچنان ناموفق است. استدلال/حریم خصوصی، کیفیت
کل زمینه، قطع WAN سرورِ همین کد، شروع سرد VM و بار پایدار پذیرفته نیستند. آزمون انتشار قبلی،
سابقهٔ تاریخ‌دار است، نه پذیرش این کد. بازیابی مستقل به دستور مالک در تعویق است، نه موفق؛
حفاظت مخزن هم به دسترسی مدیریت نیاز دارد. [کار بعدی](../NEXT_TASK.md) و [آزمون](TESTING.md)
مرجع‌اند. GitHub فقط منبع توسعه/انتشار است، نه وابستگی اجرا؛ نبود فایل، خطای روشن می‌دهد،
نه دریافت خودکار.
